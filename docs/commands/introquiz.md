# `/introquiz`

YouTube音源を使ったイントロクイズを開始・進行します。実行者のVCにBotが参加し、テキストチャンネル直下に作成されるスレッド上でゲームが進行します。

## サブコマンド

| サブコマンド | オプション                                                                                                                                                          | 実行可能場所                         | 説明                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ | ---------------------------------------------------------- |
| `start`      | `count`(出題数、デフォルト5)、`play-seconds`(1問の再生秒数、デフォルト8)、`answer-seconds`(回答受付秒数、デフォルト15)、`mode`(`intro`/`random`、デフォルト`intro`) | 通常チャンネルのみ(スレッド内は不可) | クイズを開始します。実行者がVCに参加している必要があります |
| `skip`       | なし                                                                                                                                                                | チャンネル / スレッドどちらでも可    | 現在の問題を強制終了し、正解を公開して次の問題へ進みます   |
| `stop`       | なし                                                                                                                                                                | チャンネル / スレッドどちらでも可    | セッションを終了し、最終スコアを表示してVCから退出します   |
| `score`      | なし                                                                                                                                                                | チャンネル / スレッドどちらでも可    | 進行中のセッションの途中経過スコアを表示します             |

`skip`/`stop`/`score` はサーバー(guild)単位でセッションを管理しているため、実行したチャンネルに関わらず動作します。スレッド内から実行する運用を想定しています。

## ゲームの流れ

1. `start` 実行時、コマンドを打ったチャンネルの直下に公開スレッド(`🎵イントロクイズ #<開始時刻>`)を作成し、Botが実行者のVCに接続します
2. 指定した`count`回、出題ループが続きます: 問題プールからランダムに選出(セッション内で重複なし)→ 指定秒数だけYouTube音源を再生 → スレッドで回答受付 → 最初の正解者(または`answer-seconds`経過)で正解を公開
3. 全問終了、または`/introquiz stop`で最終スコアボードを投稿し、VCを切断してスレッドをアーカイブ・ロックします

## モードについて

- `intro`: 各問題に登録した `start-seconds`(固定のイントロ開始位置)から再生します
- `random`: 各問題の `duration-seconds`(曲の総再生時間)をもとに、曲の頭5秒・末尾10秒を除いた範囲からランダムな位置を選んで再生します。曲が短すぎてこの範囲を確保できない場合は、その問題だけ自動的に`intro`扱いにフォールバックします(セッション全体のモードは変わりません)

## 必要な権限・Intent

VCでの音声再生とスレッド内メッセージの読み取りが必要です。Discord Developer Portalでの設定(Message Content Intentの有効化、Bot招待時の権限)については [README.md](../../README.md#discord-developer-portalの設定イントロクイズ機能を使う場合) を参照してください。

## 問題データの追加方法(現状)

現時点では `/quiz-question` のようなDiscordコマンドでの問題管理は未実装です。問題データはMongoDB(`MONGODB_URI`)に保存されるため、以下のいずれかの方法で投入してください。

### 方法1: `npm run seed-questions` で一括投入

`QuizQuestion` の配列をJSONファイルに用意し、まとめて投入します。`id` は省略可能で、省略時は自動採番されます。

```json
[
  {
    "guildId": "123456789012345678",
    "youtubeUrl": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
    "startSeconds": 30,
    "durationSeconds": 240,
    "title": "曲名",
    "artist": "アーティスト名",
    "answers": ["曲名", "りゃくしょう", "エイリアス"]
  }
]
```

```bash
npm run seed-questions -- ./questions.json
```

### 方法2: `mongosh` / MongoDB Compassで直接操作

`MONGODB_URI` に直接接続し、`quizQuestions` コレクションに上記と同じ形式(`id` を含む)のドキュメントを挿入・編集・削除しても構いません。

### フィールドの説明

- 問題データは全サーバー(guild)共通の1コレクションに保存されますが、`/introquiz start` はその問題を登録した `guildId` と実行サーバーが一致するものだけを出題します。複数サーバーでBotを運用する場合も、それぞれのサーバー用に問題を用意すれば混ざりません
- `guildId` はDiscordのサーバーID(開発者モードを有効にした上でサーバーアイコンを右クリック→「サーバーIDをコピー」で取得できます)
- `id` は `q001`, `q002`... の形式で、コレクション全体を通してユニークです(サーバーをまたいでも重複しません。将来Discordコマンドで管理する際の採番規則に合わせています)
- `durationSeconds` は `mode=random` でのランダム再生範囲の計算にのみ使用します
- `answers` は正誤判定に使う正解表記の配列です。判定は全角/半角・カタカナ/ひらがな・大文字小文字・空白を正規化した上での完全一致で行われます(句読点は正規化しません)
